Core Features

01 — Capabilities
01. Visualization

Threaded Tree View

Visual representation of email threads as growing branches. See exactly who replied to whom without the linear clutter.

02. Auth

Secure Google OAuth

Integrated with Google OAuth 2.0 for seamless and secure sign-in using your existing Google account.

03. Privacy

Read-Only Access

Privacy-first architecture using gmail.readonly scope. No emails are ever modified or sent.

04. Platform

Material 3 / Flutter

A contemporary Android experience built with Flutter, featuring a soothing blue-grey palette and modern UI.
